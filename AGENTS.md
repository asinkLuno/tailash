# Project Instructions

## UI

- Build application UI with GPUI and the existing `gpui-kit` components. Do not hand-roll interactive controls or widgets when GPUI or gpui-kit provides a suitable component.
- Prefer semantic components such as `Button`, `Input`, `Switch`, `Accordion`, and the kit's list/collection components. Use GPUI layout primitives (`div`, flex, grid, spacing) to compose screens.
- Check the installed gpui-kit version's API and examples before implementing UI. Keep behavior in GPUI state and event handlers, and cover user-visible interactions with UI tests.
